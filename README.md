# Netflix Data Analysis using Python

## Project Overview
This project analyzes Netflix content using Python, Pandas, Matplotlib, and Jupyter Notebook.

## Dataset
Netflix Titles Dataset

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Analysis Performed
- Movies vs TV Shows
- Top 10 Countries with Most Netflix Content
- Content Growth Over Years
- Rating Distribution
- Top Genres Analysis

## Key Findings
- Netflix contains more Movies than TV Shows.
- United States has the highest number of Netflix titles.
- India is the second-largest content producer.
- Netflix content increased significantly after 2015.
- TV-MA and TV-14 are the most common ratings.
